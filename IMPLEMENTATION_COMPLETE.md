## 🎯 Getting Started

### QUICK START (Recommended)

1. **Create Assets Folder:**
   ```bash
   mkdir assets
   ```

2. **Add Your Images:**
   - hero-image.jpg (1200x600px, <300KB)
   - about-image.jpg (600x400px, <200KB)
   - project1-6.jpg (600x400px each)
   - gallery1-9.jpg (600x600px each)

3. **Customize Your Information:**
   - Edit all HTML files
   - Replace placeholder text with your content
   - Update email, phone, social links

4. **Run Locally:**
   ```bash
   # Option A: Python
   python -m http.server 8000
   
   # Option B: Node.js
   npm install -g http-server
   http-server . -p 8000
   
   # Then visit: http://localhost:8000
   ```

5. **Deploy:**
   - GitHub Pages (free)
   - Netlify (free SSL)
   - Vercel (Next.js optimized)

## 🚢 Deployment Instructions

### GitHub Pages
```bash
# Initialize git (if not already done)
git init

# Add all files
git add .

# Commit changes
git commit -m "Complete portfolio website"

# Add remote repository
git remote add origin https://github.com/YOUR-USERNAME/portfolio.git

# Push to GitHub
git push -u origin main

# Enable Pages in GitHub settings → Pages → Select 'main' branch
```

Visit: `https://YOUR-USERNAME.github.io/portfolio`

### Netlify
1. Create account at netlify.com
2. Connect your GitHub repo

5. Deploy!
