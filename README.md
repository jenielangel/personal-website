# angel-personal-website

Scaffolded Next.js project. Follow these steps to finish setup and run locally.

## Install Node.js (Windows)
- Option A (recommended): Install Node.js LTS from https://nodejs.org/ and run the installer.
- Option B: Install `nvm-windows` (https://github.com/coreybutler/nvm-windows) and then install a Node version with `nvm install lts`.

## After installing Node.js
```powershell
cd "C:\Users\Angel\OneDrive\Desktop\Projects\angel-personal-website"
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
